💻 Opsi 2: Menjalankan Secara Lokal dari Folder ZIP

Sebagai aplikasi berbasis web modern (SPA), peramban memblokir eksekusi modul langsung dari protokol file:/// demi keamanan (CORS policy). Untuk menjalankannya di laptop Anda:

  1. Ekstrak seluruh isi file ZIP ini ke komputer Anda.
  2. Cara Otomatis: Klik dua kali file start-app.bat di dalam folder ini. Aplikasi akan otomatis terbuka di http://localhost:3000.
  3. Cara Manual via Terminal / CMD:
    npm install
    npm run dev
